# Contributors and assistance

This repository is maintained by its GitHub contributors.

## AI-assisted development

Some architecture, implementation, validation, testing, and review work has been assisted by **ChatGPT (OpenAI)**.

ChatGPT does not have an independent GitHub identity in this repository and is not an official maintainer or an OpenAI-owned repository account. Commits produced with this assistance may include:

```
Assisted-by: ChatGPT (OpenAI)
```

This trailer records tool-assisted authorship transparently without implying a separate GitHub contributor identity or transferring responsibility for review and publication decisions.
